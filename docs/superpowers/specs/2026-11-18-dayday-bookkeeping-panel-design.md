# Day-Day 记账板块设计:标准版

- 日期:2026-11-18
- 状态:已批准(设计对话确认:标准版 / B 统计先行布局 / 侧边抽屉入口 / 弹层内数字键盘 / 横向条形图)
- 范围:新增「记账」功能板块,纯离线,数据存 IndexedDB,不改动现有面板数据模型与业务规则
- 布局参考 mockup:docs/mockups/bookkeeping-variants.html(方案 B 统计先行)

## 背景与目标

Day-Day 观星台是纯离线 Capacitor Android 应用(com.dayday.app),数据存 IndexedDB。用户希望新增一个方便快捷的日常记账板块:

1. 记一笔 ≤3 秒(分类九宫格 + 弹层内数字键盘)
2. 月度支出/收入/结余总览 + 月环比 + 日均
3. 分类支出横向条形图
4. 按日期分组的账单列表,可编辑/删除
5. 视觉与现有深蓝夜空系统一致,自动适配 5 套主题

## A. 数据模型

- 新增 IndexedDB store `ledger`,一条账一条记录:
  ```
  { id, type: 'expense'|'income', amount: 整数分, category, note,
    date: 'YYYY-MM-DD', createdAt, _scope }
  ```
- `amount` 以**分**为整数存储,杜绝浮点误差;显示时 ÷100 格式化为 `¥x.xx`
- `ledger` 加入 `DATA_STORES`,full/lite 两种登录模式数据隔离(与 notes/diary 一致)
- 无预算字段(标准版不含预算)

## B. 预设分类(固定,不可自定义)

- 支出 8 类:`🍜餐饮 🚌交通 🛒购物 🎬娱乐 🏠居住 📚学习 ❤️医疗 ✨其他`
- 收入 3 类:`💼工资 🎁红包 ✨其他`
- 分类定义集中在 ledger 模块,emoji + 中文名,统计与列表共用同一份定义

## C. 入口

- 侧边抽屉(界面风格下方)加「💰 记账」按钮,点击打开记账面板
- 顶部导航保持 6 项不变;记账面板打开时导航无高亮项
- 面板内顶部有「←」返回按钮,回到观星台

## D. 面板布局(B 统计先行,自上而下)

```
‹ 2026年11月 ›                    ← 月份切换(‹ › + 当前月份文字)
┌ 本月支出 ¥1,286.5 ┐              ← 大数字卡
│ 收入 ¥3,200 · 结余 ¥1,913.5      │
│ 较上月 ↓12% · 日均 ¥43           │
┌ 支出分类(横向条形图)┐            ← 金色渐变填充条,金额排行
│ 🍜餐饮 ▓▓▓▓▓ ¥489              │
┌ 最近账单(默认 8 条,可展开全部)┐  ← 按日期分组,日头 + 条目
      (＋)                        ← 悬浮按钮 → 快速记账弹层
```

- 月份默认当前月;切换月份后总览/统计/列表整体重算重渲染
- 环比:本月支出 vs 上月同期支出,显示 `↓x%` / `↑x%`;上月无数据显示 `—`
- 日均 = 本月支出 ÷ 当月已过天数(按本地日期)

## E. 快速记账弹层

底部弹层(与现有弹窗视觉统一,backdrop-filter 可用——弹窗在规格允许清单内):

1. 支出/收入 tab 切换(默认支出)
2. 分类九宫格(支出 8 格 / 收入 3 格)
3. 弹层内数字键盘(1-9、0、`.`、`⌫`),金额实时显示在顶部大字
4. 备注(可选,单行输入)+ 日期(默认今天,可改,用原生 `<input type="date">`)
5. 「✓ 记一笔」保存:金额为 0 或无分类时按钮置灰;保存成功 → 关闭弹层 + toast + 面板数据刷新

## F. 账单管理

- 点击列表条目 → 弹出 编辑/删除 选择(复用现有弹窗模式)
- 编辑:打开记账弹层,预填原数据,保存走 update
- 删除:确认后移除,面板刷新

## G. 统计计算(纯函数,进入面板时实时计算)

- 月度数据量小(通常 <1000 条),每次进面板按 `date` 前缀过滤当月记录计算,不做缓存
- 分类汇总:按 category 聚合支出,按金额降序,条形图宽度 = 该分类金额 ÷ 最大分类金额
- 全部使用整数分运算,避免浮点累加误差

## H. 视觉与性能

- 全部颜色/圆角/间距使用现有 `var(--*)` token,自动适配 5 套主题(星夜/月白/浅蓝/深蓝/岩灰)
- 条形图纯 CSS(width % + 金色渐变),**零 canvas 重绘**
- 卡片风格与观星台一致:半透明纯色 + 1px 细边框 + 顶部微光边线;backdrop-filter 仅弹层
- 面板入场动画与其他面板一致(淡入上移),切 tab 不重播
- 数字键盘为静态 DOM 按钮,无动画开销;点击有 :active 反馈
